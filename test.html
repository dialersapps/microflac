microflac.js test page

Runs entirely in this page (no network, no build step). Each encoded file is checked three ways: (1) an independent reference decoder written for this page (bit-exact, also verifies both CRCs and every STREAMINFO field), (2) the STREAMINFO MD5 against a second, separately written MD5, and (3) the browser's own decoder, decodeAudioData.
